Skills

A skill is a folder

--- name: wallet-lookup description: Look up on-chain wallet balance and transaction history. metadata: author: chaindata version: 1.0.0 ---
# Wallet Lookup ### Step 1 — Extract the 0x address ### Step 2 — python scripts/lookup.py --address ADDR ### Step 3 — Summarise: balance, tokens, activity
scripts/ ← code, loaded on demand
references/ ← docs, loaded on demand
Level 1 — always loaded

YAML frontmatter. Tells the agent when this skill applies.

Level 2 — loaded when relevant

SKILL.md body. Step-by-step instructions, examples, guardrails.

Level 3 — fetched on demand

Scripts, references, assets. Only pulled when the agent needs them.

The case for skills

Where Agent Skills Win

Dynamic discovery

AGENTS.md is static — fixed at session start. Skills can be searched from a registry at runtime.

Executable code

AGENTS.md is documentation. A skill can run a migration, call an API, or build a container.

Packaged & versioned

One skill = one capability. Named, composable, auditable. A flat file loses all that structure.

Portable across agents

AGENTS.md lives in one repo. Skills work with Claude, GPT, Cursor, Copilot — any agent that speaks MCP.

What skills need is infrastructure that accentuates these strengths.

The attack pattern
01 Publish legitimate-looking skill
02 Require “prerequisite” helper install
03 Drop infostealer (AMOS)
04 Harvest API keys, wallets, SSH creds
The lethal trifecta Risk
Access to private data Credentials, secrets, cloud config
Exposure to untrusted content Skills, tools, plugins from open marketplaces
Ability to act externally API calls, deployments, money movement

Add persistent memory + tool invocation → autonomous supply chain attacks.

09 / 15
The countermeasures

How Enact stops each attack

Malicious upload

OIDC identity → Sigstore signing → transparency log. Block unsigned publishers.

Credential theft

Secrets injected at runtime. Never in repo, memory, or logs. Scoped to container.

Compromised version

Global revocation. Minimum version enforcement. Automatic quarantine.

Unrestricted access

Trust tiers. Verified-only installs. Mandatory isolation. No unsigned code.

Security built into the supply chain — not bolted on after.
